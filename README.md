# 🌿 BeAura – Skincare & Haircare Platform

## 📌 Project Idea

BeAura is a full-stack skincare and haircare platform that provides personalized recommendations for products, diet, and routines based on the user's face type, skin type, and hair type.

The platform also allows users to:
- Book appointments with dermatologists
- Chat with doctors
- View nearby dermatologists using maps

This project is inspired by platforms like Man Matters but designed for both men and women.

### Other:

---

## 🔌 API Endpoints

### GET APIs
- `GET /users` → Get all users
- `GET /users/:id` → Get user by ID

### POST APIs
- `POST /users` → Create new user

### PUT APIs
- `PUT /users/:id` → Update user

---
