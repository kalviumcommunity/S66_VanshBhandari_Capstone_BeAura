Project Title:
BeAura - Personalized Skincare & Haircare Platform

Frontend deploy link :- https://relaxed-truffle-1ed884.netlify.app/

Project Overview:
BeAura is a personalized skincare and haircare platform that provides tailored product recommendations, diet plans, and routine suggestions based on user biological metrics (face, skin, and hair types).

Key Features:
User Authentication & Recovery:
Secure signup, login, and robust password recovery flow.

Personalized Curation & Product Suggestions:
Custom recommendation dashboard with filtering based on biological parameters (oily vs dry).

Dermatologist Appointments:
Integrated appointment scheduler to book virtual or clinical consultations with specialists.

Clinic Finder:
Interactive search engine and map pin binder to easily discover and locate nearby network clinics.

Consultation Chat:
Real-time messaging system allowing interactive support.

Unified Profile Modal:
Access biological diagnostics and details instantly across all pages in the app.

Tech Stack:
Frontend: React.js with Tailwind CSS
Backend: Node.js with Express
Database: MongoDB (Atlas)
Version Control: GitHub
API Testing: Postman
Deployment: Backend deployed on Render, Frontend deployed on Netlify

Why This Project?
I chose this project to create a comprehensive digital ecosystem for personalized skincare and professional dermatological care. Many users lack custom, science-driven routine suggestions and a direct way to find and schedule dermatologist appointments.

Through this project, I will learn:
- Constructing data-driven personalization algorithms and database models.
- Building interactive visual elements (maps, details widgets, custom cart drawers).
- Implementing secure user flows including password resets and unified session modals.
- Syncing full-stack frontend routing with cloud database connections.
